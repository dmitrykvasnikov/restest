* Project goal
I want to make tool for testing REST API services. 

* Project description
This is application which can help user to test their tools. It should be able to response on GET / POST and other standard requests. It should have web interface for managing databases of endpoints. It should have set of simple sets of data to test without authorisation (like getting list of users or something like this). I want to have user system where user can authorise and edit / add endpoints and test datasets.
